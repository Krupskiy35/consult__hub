CONSULT HUB — ГОЛОВНА СТОРІНКА (ізольований модуль)

Скопіюйте папку Home до кореня Consult_Hub_Unified поруч із Services та Ukraine_Desk.
Відкривайте Home/index.html через локальний сервер із кореня проєкту.

Сторінка використовує ВЛАСНІ Home/style.css, Home/js/* та Home/assets/* і НЕ підключає спільний css/style.css або js/main.js. Це свідомо: у наданих незалежних проєктах однойменні файли мають різні реалізації, а їхня автоматична заміна могла б змінити дизайн/поведінку.

Підключення: Home/index.html -> style.css; js/main.js; js/flow.js; js/particles.js.
1.js у вихідному ZIP не підключався в HTML, тому збережений у Home/unused/1.js, але не виконується.

ВАЖЛИВО: вихідний CSS посилається на ../fonts/montserrat-*.woff/woff2, проте цих файлів у наданому архіві немає. Якщо шрифти не завантажуються, додайте оригінальні файли до кореневої папки fonts/ (поруч із Home), або окремо підключіть шрифт із перевіреного джерела. Не додавайте випадкові шрифти, якщо потрібна точна відповідність дизайну.

У вихідному HTML посилання en.html та it.html ведуть на не надані файли. Локально вони не відкриються, поки не додасте відповідні сторінки або не зміните URL.

Посилання index.html у меню головної веде на Home/index.html (поточна сторінка). Якщо потрібно, щоб головна відкривалася з кореневого /, налаштуйте серверний маршрут або додайте кореневий index.html із перенаправленням на /Home/index.html.

У вихідному CSS присутні селектори загального вигляду (.hero, .wrap тощо). Вони не впливають на Services/Ukraine_Desk, оскільки CSS головної підключений ЛИШЕ в Home/index.html. Не підключайте Home/style.css глобально до інших сторінок.

Для локального запуску: python -m http.server 8000
Потім: http://localhost:8000/Home/index.html

Це перевірка структури, шляхів і синтаксису; браузерний візуальний регресійний тест не проводився.
